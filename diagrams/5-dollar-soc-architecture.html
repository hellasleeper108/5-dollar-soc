5 Dollar SOC Architecture

A cheap, AI-managed security lab built for learning and daily operations practice.

Observation Layer

  • • Honeypots attract attacker traffic
  • • Real-world commands and credentials reveal behavior
  • • Isolation matters more than realism
  • • Telemetry is the real product

Intel Layer

  • • Threat feeds add context
  • • Reputation helps prioritize noise
  • • Enrichment is only useful when paired with triage
  • • Never publish raw personal IPs in a public repo

Operator Layer

  • • Daily and weekly outputs keep the loop alive
  • • Hermes Agent automates summaries and scheduling
  • • The system teaches more when the operator reads it
  • • Public repos should show story, not secrets
